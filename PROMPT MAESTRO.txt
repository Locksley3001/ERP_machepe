PROMPT MAESTRO

Quiero que actúes como un equipo completo de desarrollo de software compuesto por un arquitecto de software senior, un ingeniero backend senior, un ingeniero frontend senior, un especialista en bases de datos PostgreSQL, un diseñador UX/UI, un ingeniero DevOps y un desarrollador experto en sistemas POS y ERP para restaurantes y cafeterías.

Tu objetivo es desarrollar un sistema POS profesional completamente personalizado para mi negocio. No quiero un ejemplo, un prototipo ni una demostración. Quiero un sistema real, escalable, limpio, profesional y preparado para utilizarse en producción.

OBJETIVO GENERAL

Desarrollar una aplicación web (NO un programa de escritorio) tipo PWA (Progressive Web App), optimizada para computadores, pero que también pueda abrirse desde celulares y tablets.

La aplicación deberá almacenar toda la información en una base de datos en la nube utilizando Supabase (PostgreSQL).

La sincronización deberá ser automática entre dispositivos.

Toda la arquitectura deberá ser escalable para que pueda crecer durante muchos años.

El código debe estar completamente comentado.

Cada función importante deberá tener comentarios explicando qué hace.

Quiero que todo el proyecto tenga una estructura profesional.

NO quiero un desarrollo por fases.

Quiero que el proyecto se construya completamente.

Herramientas.

Sillas.

Mesas.

Neveras.

Licuadoras.

Todo.

Cada producto debe tener:

- Código único
- Nombre
- Categoría
- Subcategoría
- Descripción
- Unidad de medida
- Cantidad actual
- Cantidad mínima
- Cantidad máxima
- Costo de compra

- Estado

3. Compras

Cuando llegue mercancía no modificar el inventario manualmente.

Debe existir un módulo de compras.

Cada compra debe registrar

- Proveedor
- Fecha
- Número de factura
- Productos
- Cantidades
- Costos
- IVA
- Descuentos
- Total

Al guardar

Debe aumentar automáticamente el inventario.

Debe guardar historial.

Responsable.
